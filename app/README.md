# Miranda Glow · App móvil

Aplicación móvil independiente de la web, construida con Expo + React Native + TypeScript.

## Desarrollo

```bash
cd app
npm install
npx expo start
```

La implementación sigue el handoff de `Aplicación rutina de piel/design_handoff_rutina_piel` y usa el sistema visual Nocturne.
